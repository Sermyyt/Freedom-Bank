# CQA — факты для выступления

**Что мы сделали.** Система помогает проверять качество клиентских разговоров по изменяемому чек-листу. Она импортирует группы, сохраняет ревизии разговоров, оценивает критерии и связывает выводы с ID доказательств. Проверяющий видит результат, рассматривает апелляции и сравнивает оценки разных версий чек-листа. Модель выбирает ответ и объясняет его; баллы и округление рассчитывает сервер. Исходная оценка остаётся в истории после решения человека.

**Что измерено на настоящей модели.** Для базы защиты используется замороженный `cqa-v9`, модель `gpt-4.1-mini`, активный чек-лист версии 5. Это результаты конкретных запусков, а не гарантия скорости или качества на любом наборе. [Источник: DATA_NOTES](DATA_NOTES.md).

| Факт | Проверенный результат |
| --- | --- |
| Полный DEV | **65/65** разговоров обработаны |
| Время при конкуренции 4 | **636.954 секунды** |
| Расчётная стоимость полного DEV | **$0.812968** |
| Расчётная стоимость разговора | **$0.812968 / 65 = $0.0125072**, примерно **$0.0125** |
| Ошибки и ручная проверка | Нет упавших разговоров и HTTP 429; два ответа успешно повторены после валидации; один разговор отмечен для проверки человеком |
| Живая замена критерия | **4.964 секунды** на переоценку, **1 вызов модели**, **7 результатов переиспользованы** |

Создание, активация новой версии и переоценка вместе заняли **5.140 секунды**. Затем исходная активная версия восстановлена. Стоимость вычислена по токенам и тарифу; фактическое списание провайдер не вернул. [Измерения и условия](DATA_NOTES.md).

**Наше отличие — контекст фаз звонка.** Мы различаем общение с клиентом, удержание, внутреннюю консультацию и события после завершения. То, что оператор выяснил у коллеги, ещё не означает, что он сообщил это клиенту. Фаза сохраняется рядом с сообщением и учитывается при проверке доказательств. Это позволяет разбирать не только содержание ответа, но и кому, когда и в какой части разговора он был адресован. При этом ошибки интерпретации модели остаются возможными. [Разбор фаз и ограничений](QUALITY_NOTES.md).

**Честно о качестве.** В отдельном разборе сложных диалогов на `cqa-v9` из **64 ответов**: **45 согласуются** с правилами, **4 расходятся**, **15 неоднозначны**. Это разбор ассистента, не человеческая разметка и не accuracy; случаи использовались при настройке. Завершение полного DEV не подтверждает смысловую правильность каждой оценки. [Источник: QUALITY_NOTES](QUALITY_NOTES.md).

Историческая проверка повторяемости **cqa-v5** дала **440/512 совпавших ответов — 85.9375%** на одинаковых входах. Это **не измерение cqa-v9 и не точность относительно gold**; менялись также итоговые баллы и один грубый флаг. Человеческой gold-разметки на момент подготовки нет: eval_gold — **0 файлов, 0 сравнений, accuracy=null**. Обоснования, неоднозначные случаи и грубые нарушения требуют контроля человека. [Повторяемость и ограничения](QUALITY_NOTES.md).
